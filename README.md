# 首爾住宿站點與仁川 AREX 比較

先比較住首爾站、弘大入口或雲西的機場交通，再查住宿地址和出口。快車和站站停的停靠差異可直接在命令列查詢。

## 資料與工具

| 分類 | 站點 | 方式 | 出發前核對 |
|---|---|---|---|
| 首爾站 | 서울역 | 直達車、站站停 | 適合先查首爾站附近住宿或銜接其他鐵路，記下飯店所處出口。 |
| 弘大入口 | 홍대입구 | 站站停 | 可直接搭站站停到弘大入口，再確認飯店是否在同側出口。 |
| 孔德 | 공덕 | 站站停 | 適合把孔德作為市區換乘點，按旅館地址確認末段交通。 |
| 金浦機場 | 김포공항 | 站站停 | 若要接駁另一機場的航班，另留移動至航廈與報到時間。 |
| 雲西 | 운서 | 站站停 | 若選機場周邊住宿，核對實際站點及早班機的到場安排。 |
| 仁川 T1 | 인천공항1터미널 | 直達車、站站停 | 搭乘前依航班核對航廈。 |
| 仁川 T2 | 인천공항2터미널 | 直達車、站站停 | 搭乘前依航班核對航廈。 |

[下載 CSV](travel-data.csv)。欄位包括交通分類、站點、方式、行前查核事項、來源與核對日期。需要票價、班次或無障礙動線時，請在出發前查相應營運方。

## 使用方式

執行 `python3 plan.py "直達車"`，或省略條件列出全部。工具使用 Python 3 標準函式庫。

[開啟獨立住宿區位資料集](hotel-areas/README.md)，可下載 CSV／JSON 及查看逐列來源。
